pub fn swap_remove_entry(self) -> (K, V)

Removes this entry from the map and yields its corresponding key and value.

Like Vec::swap_remove, the value is removed by swapping it with the last element of the map and popping it off. This perturbs the position of what used to be the last element!.

Removes this entry from the map and yields its corresponding key and value.

Like Vec::remove, the pair is removed by shifting all of the elements that follow it, preserving their relative order.

Computes in O(n) time on average
