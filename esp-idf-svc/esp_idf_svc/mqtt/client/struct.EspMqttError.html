Struct EspMqttError 

Source 
pub struct EspMqttError(/* private fields */);
Expand description

An MQTT error event, including the error details supplied by ESP-IDF.

Error payloads borrow these details from ESP-IDF for the event lifetime. Copy the error to retain a snapshot. Check Self::error_type before interpreting the other fields: TLS and socket errors apply to transport failures, while the connect return code applies to connections refused by the broker.

ESP-IDF does not reset every field for each error. Fields unrelated to Self::error_type may contain stale values from an earlier error and must not be interpreted as details of the current error. For example, a broker refusal may retain the socket errno from an earlier transport failure.
