Struct EspError 

Source 
pub struct EspError(/* private fields */);
Expand description

A wrapped esp_err_t to check if an error occurred.

An esp_err_t is returned from most esp-idf APIs as a status code. If it is equal to ESP_OK it means no error occurred.
