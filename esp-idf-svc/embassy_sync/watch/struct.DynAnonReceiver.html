Struct DynAnonReceiver 

Source 
pub struct DynAnonReceiver<'a, T: Clone>(/* private fields */);
Expand description

A receiver that cannot .await value, which holds a dynamic reference to a Watch channel.

This is an alternative to AnonReceiver with a simpler type definition, at the expense of some runtime performance due to dynamic dispatch.
